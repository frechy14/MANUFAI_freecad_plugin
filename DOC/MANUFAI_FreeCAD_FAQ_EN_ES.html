Información generalOverview

¿Qué es MANUFAI para FreeCAD?What is MANUFAI for FreeCAD?

Es un banco de trabajo para FreeCAD orientado a trayectorias de soldadura. Permite crear soldaduras a partir de geometría CAD, asignar datos del proceso, revisar secuencias y preparar información para simulación y exportación.

It is a FreeCAD workbench for welding paths. It lets you create welds from CAD geometry, assign process data, review sequences, and prepare information for simulation and export.

¿Qué herramientas incluye?Which tools does it include?

La documentación organiza las herramientas en MANUFAI Workbench, alineación 3-2-1, C3P – WdCurve y automatización con RoboDK. Las opciones visibles dependen de los componentes instalados y activados.

The documentation groups the tools into MANUFAI Workbench, 3-2-1 alignment, C3P – WdCurve, and RoboDK process automation. The visible options depend on the installed and enabled components.

¿Necesito RoboDK para crear soldaduras en FreeCAD?Do I need RoboDK to create welds in FreeCAD?

No. Puedes definir las trayectorias dentro de FreeCAD. RoboDK interviene cuando quieres transferir geometría o datos de soldadura para preparar y revisar programas de robot.

No. You can define welding paths in FreeCAD. RoboDK comes into the workflow when you want to transfer geometry or weld data to prepare and review robot programs.

02

Instalación y licenciaInstallation and license

¿Cómo instalo MANUFAI?How do I install MANUFAI?

Descarga el instalador para Windows desde el sitio de MANUFAI, sigue el asistente y reinicia FreeCAD. Antes de instalar, consulta la versión de FreeCAD requerida en la documentación de la versión que descargaste.

Download the Windows installer from the MANUFAI website, follow the setup wizard, and restart FreeCAD. Before installing, check the FreeCAD version required by the documentation for the release you downloaded.

¿Cómo activo la licencia?How do I activate the license?

Selecciona el banco de trabajo MANUFAI, abre Activator, introduce tu clave de serie, agrégala con + y pulsa Activate. La clave se obtiene mediante los canales indicados por MANUFAI.

Select the MANUFAI workbench, open Activator, enter your serial key, add it with +, and select Activate. Get the key through the channels specified by MANUFAI.

¿Puedo elegir qué barras de herramientas se muestran?Can I choose which toolbars are shown?

Sí. Abre Modifier, marca los componentes que quieras mostrar y aplica los cambios con Install. Reinicia FreeCAD para actualizar las barras. MANUFAI Workbench es el componente obligatorio.

Yes. Open Modifier, select the components you want to display, and apply the changes with Install. Restart FreeCAD to update the toolbars. MANUFAI Workbench is the required component.

¿Qué hago si MANUFAI no aparece en FreeCAD?What should I do if MANUFAI does not appear in FreeCAD?

Reinicia FreeCAD y revisa el selector de bancos de trabajo. Si sigue sin aparecer, comprueba que la instalación terminó, que el complemento quedó en la carpeta Mod de la instalación de FreeCAD que estás usando y que la versión de FreeCAD coincide con la indicada para tu instalador.

Restart FreeCAD and check the workbench selector. If it still does not appear, make sure installation completed, the plugin was placed in the Mod folder of the FreeCAD installation you are using, and your FreeCAD version matches the one specified for your installer.

03

Crear soldadurasCreating welds

¿Tengo que detectar las uniones soldables automáticamente?Do I have to detect weldable joints automatically?

No. Extract Edges y Find Weld Edges ayudan a identificar candidatos en el modelo, pero también puedes seleccionar aristas directamente para definir las soldaduras.

No. Extract Edges and Find Weld Edges help identify candidates in the model, but you can also select edges directly to define welds.

¿Cómo creo una soldadura a partir de una arista?How do I create a weld from an edge?

Abre un modelo CAD, selecciona la arista que seguirá la soldadura y usa la herramienta de conversión a trayectoria o Weld Creator, según el tipo de soldadura que necesites. Antes de continuar, revisa la trayectoria creada en la vista 3D.

Open a CAD model, select the edge the weld should follow, and use the path conversion tool or Weld Creator, depending on the weld you need. Check the resulting path in the 3D view before proceeding.

¿Se pueden crear soldaduras sobre curvas?Can I create welds along curves?

Sí. Las trayectorias pueden seguir aristas rectas o curvas del modelo. Comprueba visualmente el resultado, en especial cuando la geometría contiene varios segmentos o curvas cerradas.

Yes. Paths can follow straight or curved model edges. Inspect the result visually, especially when the geometry contains multiple segments or closed curves.

¿Puedo limitar la longitud o crear soldaduras intermitentes?Can I limit the length or create intermittent welds?

Sí. Weld Creator incluye opciones para definir tramos de longitud específica y patrones intermitentes. En estos últimos se configuran la longitud de los cordones y la separación entre ellos.

Yes. Weld Creator provides options for specific-length segments and intermittent patterns. For intermittent welds, you set bead length and spacing between beads.

¿Para qué sirven las normales de una soldadura?What are weld normals used for?

Las normales aportan información de orientación para la antorcha respecto de la trayectoria y las superficies cercanas. La herramienta de cálculo de normales permite revisar y ajustar esa orientación antes de trabajar con trayectorias de robot.

Normals provide torch orientation information relative to the path and nearby surfaces. The normal-calculation tool lets you inspect and adjust that orientation before working with robot paths.

¿Por qué una herramienta no acepta el objeto que seleccioné?Why does a tool reject the object I selected?

Algunas herramientas requieren una arista del CAD o una soldadura existente, y no el cuerpo completo. Comprueba qué tipo de selección pide el panel y selecciona el elemento directamente en la vista 3D. Si aparece un error, consulta Report view para ver el mensaje exacto.

Some tools require a CAD edge or an existing weld rather than an entire body. Check the selection type requested by the panel and select that element directly in the 3D view. If an error appears, read the exact message in Report view.

04

Simulación y datosSimulation and data

¿Cómo se define el orden de las soldaduras?How is the welding order defined?

Asigna valores de Sequence a las soldaduras y revisa el orden en las herramientas de secuencia o en Line Weld Table. La tabla también permite editar parámetros del proceso, como corriente, voltaje y velocidad, cuando correspondan.

Assign Sequence values to welds and review their order with the sequence tools or in Line Weld Table. The table can also edit process parameters such as current, voltage, and speed when applicable.

¿Qué muestra la simulación de soldadura?What does the welding simulation show?

Permite recorrer las trayectorias y revisar visualmente el orden y la dirección de ejecución. Es una revisión virtual del plan de soldadura; los movimientos de robot y el proceso físico deben comprobarse por separado en el entorno correspondiente.

It lets you play through the paths and visually inspect execution order and direction. It is a virtual review of the welding plan; robot movements and the physical process must be checked separately in the relevant environment.

¿Qué puedo enviar a RoboDK?What can I send to RoboDK?

Las herramientas documentadas permiten exportar el conjunto CAD completo o las piezas seleccionadas y transferir datos de trayectorias para generar programas en RoboDK. Revisa la estación, los targets y la ejecución del programa en RoboDK después de la transferencia.

The documented tools can export the entire CAD assembly or selected parts and transfer welding path data to generate programs in RoboDK. Check the station, targets, and program execution in RoboDK after transfer.

¿Se pueden importar archivos de trayectorias de soldadura?Can I import welding path files?

Sí. Weld Loader Pro documenta la importación de archivos .WDCurve y .cwsf, con datos como geometría, secuencia y parámetros del proceso presentes en el archivo. Revisa las soldaduras importadas en el documento antes de utilizarlas.

Yes. Weld Loader Pro documents import of .WDCurve and .cwsf files, including geometry, sequence, and process parameters available in the file. Check imported welds in the document before using them.

¿Qué datos pueden aparecer en los reportes?Which data can appear in reports?

La documentación menciona longitud total de soldadura, estimaciones de consumo de material y tiempos de operación. Revisa los parámetros del proyecto y los resultados antes de emplear esas estimaciones para tomar decisiones.

The documentation mentions total weld length, estimated material consumption, and operation times. Check project parameters and results before using those estimates to make decisions.
